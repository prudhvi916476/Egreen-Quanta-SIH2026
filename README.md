# Egreen Quanta (SIH 2026)

Egreen Quanta is an AI-Powered Interactive Quantum Algorithm Learning Platform. This repository is the starting point for our Smart India Hackathon (SIH) 2026 project.

## 🏗️ Architecture

- **Frontend**: React + Vite + Tailwind CSS + Shadcn UI (to be developed in the `frontend/` directory).
- **Backend**: FastAPI + Python (to be developed in the `backend/` directory).

## 🚀 Getting Started

### 1. Backend Setup

```bash
cd backend
python -m venv venv
# Windows: venv\Scripts\activate
# Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
